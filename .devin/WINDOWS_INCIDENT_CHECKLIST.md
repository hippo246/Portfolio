# Windows Troubleshooting Incident Review Checklist

**Purpose:** This is a private checklist to help you recognise Windows 10 and Windows 11 issues you may have actually handled. Do not publish this file. Review each item and confirm whether you genuinely encountered it before adding it to your public portfolio.

---

## Windows Updates

- [ ] Windows updates failing or getting stuck
  - Did you help someone with Windows Update errors?
  - Was the update stuck at a certain percentage?
  - Did error codes appear (e.g., 0x80070643, 0x80070005)?
  - What troubleshooting steps did you try?

- [ ] Problems after specific updates
  - Did a friend's PC develop issues after a particular update?
  - What were the symptoms?
  - How did you resolve it (e.g., uninstall update, System Restore, Safe Mode)?

---

## System Performance

- [ ] PC running slowly
  - Did you help troubleshoot a slow Windows PC?
  - Was the slowness at startup, during use, or both?
  - Did you check Task Manager for high CPU/RAM/disk usage?
  - What did you find?

- [ ] High CPU, RAM, or disk usage
  - Did you identify specific processes causing high resource usage?
  - Were there startup programs or background services consuming resources?
  - Did you disable or remove anything?

- [ ] Application crashes or freezes
  - Did a specific app crash repeatedly?
  - Did the entire system freeze?
  - Did you check Event Viewer or error logs?

---

## Networking & Connectivity

- [ ] Wi-Fi connected but no internet access
  - Did you help someone with this issue?
  - Did you check IP configuration, DNS, or gateway settings?
  - Did network reset or adapter reset help?

- [ ] Bluetooth devices refusing to connect
  - Did a Bluetooth headset, mouse, or keyboard fail to connect?
  - Did you check Bluetooth drivers or services?
  - Did you remove and re-pair the device?

- [ ] Ethernet not working
  - Did the wired network connection fail?
  - Did you check cable, port, or adapter status?
  - Did you try updating network drivers?

---

## Hardware & Drivers

- [ ] Device recognition problems
  - Did a printer, camera, microphone, or other device not appear in Windows?
  - Did you check Device Manager for missing drivers?
  - Did you install drivers from manufacturer websites?

- [ ] Audio, microphone, or camera not working
  - Did you troubleshoot sound issues?
  - Did you check audio device settings or app permissions?
  - Did you test with different apps or devices?

- [ ] Driver errors in Device Manager
  - Did yellow exclamation marks appear for devices?
  - What was the error code or message?
  - Did you update, rollback, or reinstall drivers?

---

## Storage & File Systems

- [ ] Storage space running low
  - Did you help someone free up disk space?
  - Did you use Storage Sense, Disk Cleanup, or manual deletion?
  - Did you check for large files or duplicate data?

- [ ] Drive recognition or access issues
  - Did an external drive not appear?
  - Did you check Disk Management or assign drive letters?
  - Was the drive corrupted or formatted incorrectly?

- [ ] File or folder permission problems
  - Did someone get "Access Denied" errors?
  - Did you check ownership or NTFS permissions?
  - Did you modify permissions or take ownership?

---

## Startup, Boot & Recovery

- [ ] Startup problems
  - Did a PC fail to boot or get stuck on a loading screen?
  - Did you use Safe Mode, Startup Repair, or recovery media?
  - What was the cause and resolution?

- [ ] Blue Screen of Death (BSOD)
  - Did you encounter BSOD errors?
  - What was the error code (e.g., CRITICAL_PROCESS_DIED, MEMORY_MANAGEMENT)?
  - Did you check dump files or update drivers?

- [ ] System recovery or reset
  - Did you help someone use System Restore?
  - Did you perform a Windows reset or clean install?
  - Was data backed up before recovery?

---

## Applications & System Configuration

- [ ] Software installation or compatibility issues
  - Did an app fail to install or run?
  - Was it due to compatibility, permissions, or missing dependencies?
  - Did you try compatibility mode or alternative versions?

- [ ] Windows settings behaving unexpectedly
  - Did settings change on their own or not save?
  - Did you check Group Policy, registry, or configuration files?
  - Did you reset settings to defaults?

- [ ] Services or startup apps causing problems
  - Did a service fail to start or consume resources?
  - Did you disable problematic startup items?
  - Did you use Task Manager or Services.msc?

---

## Instructions for Adding to Portfolio

1. **Only add incidents you genuinely remember and can describe.**
2. **Distinguish what you actually did from what you could have done.**
3. **Be specific about tools and steps you used.**
4. **If you don't remember exact details, leave it as a category summary rather than a detailed incident.**
5. **Mark any uncertain details as "requires confirmation" or leave them out.**

---

## Notes

- This checklist is for memory jogging only.
- Do not invent incidents to fill gaps.
- Honest, specific incidents are better than generic, unsupported claims.
- Quality of evidence matters more than quantity of incidents.
