Factory CRM

Factory-oriented management prototype

← Back to Portfolio

Project Overview

Factory CRM (internally named Paratha CRM) is a comprehensive factory and manufacturing management system built with React 18 and Firebase. It addresses the complete operational workflow of a manufacturing business — from production planning and raw material inventory management through to finished goods tracking, delivery logistics, GPS-based field agent monitoring, payment processing, financial reporting (including P&L analysis), and advanced predictive analytics.

The system was designed to solve real manufacturing pain points: lack of visibility into production schedules, manual inventory tracking errors, inability to track field agents and delivery vehicles in real-time, fragmented financial data across spreadsheets, and no predictive insights for stock-outs or customer churn.

Built with AI-assisted development using Kiro, Devin (formerly Windsurf), Antigravity, Trae, and Claude. My contribution involved defining manufacturing workflow requirements across all modules by studying real factory operations, designing the role-based permission system from scratch to handle complex access control needs, creating the GPS tracking architecture with browser location APIs and permission handling, implementing the unified export engine for multiple formats, designing the predictive analytics system, testing functionality across different scenarios, and iterating on the interface based on usability feedback.

Problem Statement

Manufacturing businesses, especially small to mid-sized operations, often struggle with fragmented systems. Production planning happens in one tool, inventory in another, deliveries are tracked via phone calls, and financial data lives in spreadsheets. This fragmentation leads to:

  • No real-time visibility: Management cannot see what's being produced, what's in stock, or where deliveries are at any given moment
  • Manual errors: Data entry across multiple systems leads to inventory discrepancies and billing mistakes
  • Inefficient field operations: Field agents and delivery vehicles operate without GPS tracking, making route optimization and accountability difficult
  • No predictive insights: Businesses react to stock-outs and customer churn after they happen, rather than predicting and preventing them
  • Permission chaos: With different roles (factory workers, field agents, managers, admins), access control becomes manual and error-prone

Factory CRM was built to consolidate all these operations into a single, cohesive system with real-time data flow, role-based access control, and predictive analytics.

Solution Approach

The solution takes a module-based architecture where each operational area (Production, Inventory, Deliveries, Payments, etc.) is a self-contained tab with its own data model and UI, but all sharing a centralized Firebase Firestore database for real-time synchronization. Key architectural decisions:

  • Centralized Firebase backend: All data lives in Firestore with real-time listeners, ensuring that changes in production immediately reflect in inventory and vice versa
  • Role-based permission system: A granular permission matrix where each role (Admin, Factory, Agent) has specific access to tabs, widgets, and quick actions — enforced at both the UI and data level
  • Service layer pattern: Business logic is extracted into service classes (ActivityService, FinancialService, CustomerService, etc.) to keep components clean and testable
  • Unified export engine: A single export system that can generate PDFs, Excel files, CSVs, delivery labels, and WhatsApp shares from any module
  • GPS tracking integration: Browser location APIs with permission prompts, manual fallbacks, and live ping writing to track field agents and delivery vehicles
  • Predictive analytics: On-device and server-side predictions for stock-outs, churn risk, and demand forecasting based on historical data

Implemented Features

Production & Operations

  • Production Tab — production planning with daily/weekly targets, item-level production tracking against targets, production reports showing variance between planned and actual, batch tracking for quality control, and production efficiency metrics
  • Inventory — comprehensive stock management with raw materials and finished goods tracking, supply chain supplier management, low stock alerts with reorder thresholds, stock-in/stock-out transaction logging, and inventory valuation reports
  • Machines — equipment registry with specifications, maintenance scheduling and tracking, operational status monitoring (running/idle/maintenance), downtime logging, and preventive maintenance reminders
  • Vehicles — fleet management with vehicle registration, maintenance records, fuel tracking, insurance expiry alerts, delivery assignment capabilities, and vehicle utilization metrics
  • Deliveries — delivery scheduling with time slots, route planning optimization, GPS tracking integration for real-time delivery status, proof of delivery (photo/signature), delivery performance analytics, and customer notifications

Financial Management

  • Payments — payment processing with multiple payment modes (cash, bank transfer, UPI, cheque), invoice generation and management, payment tracking against invoices, aging reports for overdue payments, and payment reconciliation
  • Expenses — expense logging with category-based organization (raw materials, utilities, salaries, maintenance), expense approval workflows, budget vs actual variance reporting, and expense trend analysis over time
  • Wastage — waste tracking with reason codes (production defect, expiry, damage, theft), cost impact analysis, waste reduction reporting with trend lines, and root cause analysis reports
  • P&L (Profit & Loss) — comprehensive financial reporting with revenue breakdown by product and customer, cost of goods sold calculation, gross margin analysis, operating expense tracking, net profit visualization, and period-over-period comparison
  • Analytics — sales trends with line charts showing daily/weekly/monthly patterns, production metrics with efficiency dashboards, performance KPIs for staff and machines, customer segmentation analysis, and demand forecasting charts using Recharts

Customer & Staff Management

  • Customers — comprehensive customer records with contact information, purchase history with order timeline, financial summaries including outstanding balances and credit limits, payment behavior tracking, and churn risk indicators
  • Staff — employee records with role assignments, attendance tracking, performance metrics (orders processed, deliveries completed, targets achieved), shift scheduling, and productivity dashboards
  • GPS Tracking — live location tracking for field agents using browser Geolocation API, delivery vehicle tracking with route visualization, location permission management with user-friendly prompts, manual location checking as fallback, location history logging for audit trails, and geofencing capabilities for route deviation alerts

Advanced Features

  • Role-Based Permissions — fine-grained permission system with three core roles (Admin, Factory, Agent) plus custom role definitions, tab-level access control determining which modules each role can see, widget permissions controlling dashboard elements, quick action permissions for operation-specific buttons, and permission inheritance with role templates
  • Predictive Analytics — stock-out prediction based on consumption patterns and lead times, churn risk analysis using customer behavior signals (order frequency, payment delays, complaints), demand forecasting for production planning, and predictive alerts surfaced in the dashboard
  • Collaboration — real-time presence indicators showing which users are currently active, editing notifications when multiple users work on the same record, activity timeline showing complete audit trail of all changes, and conflict resolution for concurrent edits
  • Export System — unified export engine capable of generating PDFs with custom templates, Excel files with multiple sheets and formatting, CSV exports for data portability, delivery labels with barcodes and routing information, invoice generation with GST breakdown, receipt printing, and WhatsApp sharing for instant customer communication
  • Command Palette — keyboard-driven navigation (Ctrl/Cmd + K) for power users, quick search across all modules and records, fast action execution without mouse clicks, and customizable command shortcuts
  • Draggable Widgets — customizable dashboard layout where users can drag and drop widgets, widget personalization with size and visibility controls, per-user dashboard configuration persistence, and widget-specific data refresh intervals
  • Kanban Board — visual workflow management for production orders and delivery tasks, drag-and-drop status transitions, column customization per workflow type, and automatic status updates triggering downstream actions
  • Security — passkey management for passwordless authentication, security session tracking with device fingerprinting, failed login attempt monitoring with alert thresholds, soft-delete functionality for all records with trash recovery, audit logging for all data modifications, and role-based data filtering
  • Quick Entry — floating action button (FAB) for rapid data entry from anywhere in the app, quick entry bar for commonly used actions, keyboard shortcuts for frequent operations, and smart defaults based on context
  • Multi-platform Support — Capacitor integration for native iOS and Android apps with platform-specific optimizations, Tauri for desktop applications (Windows, Mac, Linux), shared codebase across all platforms with platform conditionals, and native feature access (camera, GPS, notifications)

Technology Stack

  • Frontend: React 18, React Router DOM
  • Backend / Database: Firebase (Firestore, Auth)
  • Charts: Recharts
  • PDF / Print: jsPDF, jspdf-autotable
  • Spreadsheets: xlsx (Excel export)
  • QR Codes: qrcode, html5-qrcode
  • Email: EmailJS
  • Drag & Drop: @dnd-kit
  • Mobile/Desktop: Capacitor (iOS/Android), Tauri (desktop)
  • Styling: Tailwind CSS

Development Process

The project followed an iterative development process with AI-assisted coding:

  • Requirements gathering: Studied real manufacturing operations to understand pain points, interviewed factory managers and operators, documented workflows for production, inventory, deliveries, and finance
  • Architecture design: Chose Firebase for real-time data synchronization, designed a tab-based module architecture for scalability, planned the role-based permission system early to avoid refactoring
  • Incremental implementation: Built modules one at a time starting with core features (Production, Inventory, Customers), then added advanced features (GPS, Analytics, Predictive), and finally polished UX (Command Palette, Draggable Widgets)
  • AI-assisted development: Used Kiro for code generation and refactoring, Devin (formerly Windsurf) for debugging and optimization, Antigravity for architecture decisions, Trae for UI component building, and Claude for documentation and problem-solving
  • Testing and iteration: Tested each module with demo data, gathered feedback on usability, fixed bugs discovered during testing, and iterated on the interface based on user experience

Challenges & Lessons Learned

  • Designing a role-based permission system that works across tabs, widgets, and quick actions while maintaining security
  • Implementing GPS tracking with browser location APIs while handling permission prompts and manual fallbacks
  • Building a unified export engine that can handle PDF, Excel, CSV, and delivery labels from a single interface
  • Managing real-time collaboration features like presence indicators and editing notifications without overwhelming the UI
  • Integrating predictive analytics for stock-outs and churn risk while keeping the system performant
  • Supporting multiple platforms (web, iOS, Android, desktop) with Capacitor and Tauri while maintaining a single codebase
