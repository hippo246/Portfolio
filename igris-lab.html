AI-powered internship launch platform — Vanilla HTML, CSS, JavaScript

← Back to Portfolio

Project Overview

IGRIS LAB is a full internship management and launch platform with two distinct layers — a polished public marketing site for prospective students, mentors, and recruiters, and a private student portal with a complete internship management workspace.

Built entirely in vanilla HTML, CSS, and JavaScript — no framework, no build step. The design uses a consistent dark black and orange glow aesthetic across every view. Built with AI-assisted development. My contribution involved defining the product requirements, designing all workflows and page structures, and testing across every role.

The platform supports four roles: Students, Mentors, Recruiters, and Admins.

Technology Stack

  • Frontend: Vanilla HTML, CSS, JavaScript — no framework, no build step, no dependencies
  • Architecture: Single-page application pattern with JavaScript shell switching; landing, auth, and app shells rendered conditionally
  • Design system: Custom dark black and orange glow palette, consistent across all views from landing to admin panel
  • Routing: Client-side page switching via switchPage() and showApp() functions

Challenges & Lessons Learned

  • Building a full multi-role SPA (Students, Mentors, Recruiters, Admins) in vanilla JS — state management, role-based views, and navigation all had to be implemented from scratch without a framework or router library
  • Keeping a consistent design system across 15+ views without CSS variables or a component library — required disciplined custom CSS architecture
  • The AI chat bubble positioning — on mobile the sidebar drawer overlaps the right side, so the bubble had to be detected and moved to the left when the drawer is open
  • Designing the task Kanban, internship timeline, and certificate preview to feel polished in plain HTML without any JS UI framework
