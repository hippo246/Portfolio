Hotel Network Floorplan Design — Enterprise Security Project

Status: Completed

Tools: Cisco Packet Tracer · Cisco 2911 Router · Cisco 2960 Switches

Scope: Full enterprise-grade hotel network across six zones — 6 guest rooms, guest corridor (4 APs), lobby/front desk, restaurant, back office, and server room. Hierarchical topology with a core switch (SW-CORE) and central router (R1) handling all inter-VLAN routing, DHCP, NAT/PAT, and ACL enforcement.

VLAN design: 5 VLANs (Guest/10, Lobby/20, Restaurant/30, Back Office/40, Servers/50) + VLAN 99 dead VLAN for all unused ports. Native VLAN 99 on all trunk ports to prevent VLAN hopping.

Security hardening applied to every device: SSH v2 only (Telnet disabled), RSA 1024 keys, enable secret, service password-encryption, banner MOTD, exec-timeout 5 0, no ip domain-lookup, local admin account, BPDU Guard on all access ports, Storm Control (broadcast threshold 20%), DHCP Snooping, Dynamic ARP Inspection (DAI), Rapid PVST with SW-CORE as root bridge, and all unused ports administratively shut down.

ACLs: BLOCK-INBOUND (blocks external traffic targeting internal gateways), GUEST-POLICY (guests get internet only, blocked from all internal VLANs), BLOCK-BACKOFFICE (restaurant and guest traffic cannot reach back office).

Other: Centralised DHCP on R1 with per-VLAN pools, NAT/PAT overload to single public IP, NTP synchronised across all switches from R1 master, logging buffered on R1.

Windows 11 KB5121003 — Games Crashing, BSODs After August 2026 Update

Resolved

Environment: Friends' Windows 11 PCs (builds 24H2 / 25H2)

Reported symptoms: Games freezing mid-session, closing unexpectedly, and Blue Screen of Death (BSOD) errors. Problems appeared shortly after a Windows Update the users identified as KB5121003, released on 11 August 2026.

Background: KB5121003 is a confirmed problematic update. Microsoft acknowledged it causes game crashes and system instability on affected machines. The root cause is a conflict with inpoutx64.sys — a kernel driver commonly bundled with RGB peripheral software (keyboards, mice, headsets with lighting). On systems where this driver was present, launching certain games triggered crashes or BSODs. Not all systems were affected.

Reasoning for Safe Mode: Because the update had already been installed and the system was unstable at normal boot, Safe Mode was the right starting point — it loads only essential drivers, bypassing the conflicting driver and making it possible to reach Settings and uninstall the update without triggering another crash.

Recovery steps taken:

  • Guided friends through booting into Safe Mode (via Settings → Recovery → Advanced startup, or Shift + Restart)
  • Navigated to Settings → Windows Update → Update history → Uninstall updates
  • Located and uninstalled KB5121003
  • Restarted to normal mode and confirmed system stability
  • Advised pausing Windows Updates temporarily to prevent the update reinstalling automatically

Recommended follow-up (not confirmed as personally performed):

  • Check Device Manager for any driver errors flagged after recovery
  • Review Update history to confirm the uninstall completed cleanly
  • Test the originally crashing games to confirm symptoms resolved
  • If RGB peripheral software is present: check whether an updated version of the software or driver is available that resolves the inpoutx64.sys conflict
  • Re-enable Windows Updates once Microsoft releases a fixed version of the patch

Note: KB5121003 is a verified update (released 11 August 2026, affecting Windows 11 builds 26100.9168 and 26200.9168). Microsoft officially confirmed the game-crash issue. Not every machine was affected — those without RGB peripherals or the conflicting driver likely had no problems.

Windows 11 — Wi-Fi and Bluetooth Icons Disappearing or Not Working

Resolved

Environment: Friends' Windows 11 laptops

Reported symptoms: Wi-Fi or Bluetooth icon missing from the taskbar or system tray, toggle unavailable in Quick Settings, or adapter showing as absent despite the hardware being physically present.

Important distinction: These symptoms can mean different things. A missing icon or greyed-out toggle doesn't necessarily mean the adapter is broken — it can be a UI glitch, a disabled service, or a driver issue. Connectivity itself may still be working even when the icon disappears.

Diagnostic areas investigated:

  • Device Manager: Checked whether the Wi-Fi or Bluetooth adapter was listed, and whether it showed any warning flags (yellow triangle = driver issue, hidden device = disabled)
  • Adapter status: Confirmed the adapter was enabled and not showing an error code
  • Windows services: Relevant services (WLAN AutoConfig for Wi-Fi, Bluetooth Support Service) need to be running for the adapters to function and appear in the UI
  • Taskbar / Quick Settings layout: Windows 11 allows customisation of Quick Settings — the icon being absent can sometimes simply mean it was removed from the panel rather than a hardware or driver fault

Recommended follow-up (not confirmed as personally performed in these incidents):

  • Run the built-in Internet Connections or Bluetooth troubleshooter as a first non-destructive step
  • Update or reinstall the adapter driver via Device Manager if a driver issue is confirmed
  • Check Windows Update — driver updates sometimes ship through Windows Update rather than Device Manager alone
