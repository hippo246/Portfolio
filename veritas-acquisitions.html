Veritas Acquisitions Ltd

Property acquisitions company website — HTML, CSS, JavaScript

← Back to Portfolio

Project Overview

A multi-page professional website for Veritas Acquisitions Ltd, a property deal packaging company registered in England and Wales. The site presents the company's acquisition services to potential investors, documents compliance credentials, introduces the director, and provides a formal complaints procedure.

Built in vanilla HTML, CSS, and JavaScript — no framework, no build tooling. Shared navigation and footer are loaded via JavaScript modules. The design uses a dark forest green and gold palette to reflect the premium, professional nature of the service.

Pages & Features

  • Home — full-viewport hero with property photography, "Acquisition. Integrity. Veritas." headline, client name and company number (covered for privacy), Enquire Now CTA
  • About — The Veritas Mandate — company description as a property deal packaging business connecting investors to motivated sellers across England and Wales; Compliance Ledger panel showing Company No, PRS Membership No, ICO Registered (Data Protection), and AML Status (Awaiting HMRC Supervision Approval)
  • Directors — director profile card with appointment date (01 May 2026 — Present), role description, and LinkedIn link; company registration footer
  • Complaints — formal complaints submission form (Full Name, Email, Subject, Complaint text, Submit Complaint); contact email for formal complaints; Property Redress Scheme membership card with PRS Membership No and escalation instructions
  • Footer — four-column layout: Veritas Acquisitions Ltd branding and description; Navigation links; Compliance column (Company No, PRS Membership, ICO Registered, AML Status); Redress Scheme panel with PRS logo; director name and "England & Wales" attribution

Privacy: The client name, company number, PRS membership number, and director name are intentionally covered in these screenshots at the client's request.

Technology Stack

  • Frontend: Vanilla HTML, CSS, JavaScript — no framework, no build step
  • Architecture: Multi-page static site; navigation and footer loaded via shared JS modules (nav.js, footer.js)
  • Design: Custom CSS with dark green / gold brand palette, full-viewport hero sections, responsive layout

Challenges & Lessons Learned

  • Financial services sites have a very different tone requirement — formal, trust-oriented, compliance-forward — compared to operational software
  • Sharing nav and footer across pages without a build tool meant using JS module imports to dynamically inject shared HTML, keeping the markup DRY
  • Compliance information (PRS membership, ICO registration, AML status, company number) needed to be prominently displayed but clearly structured — the Compliance Ledger panel design solves this
